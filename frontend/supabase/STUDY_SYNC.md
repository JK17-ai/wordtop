# 학습 기록 동기화 1차

`migrations/202609270003_study_sync.sql`만 기존 프로젝트에 적용합니다.
기존 foundation/초대코드 SQL을 다시 실행하지 않습니다.

- 프로필은 인증 기기의 `profile_accounts`에서 서버가 결정합니다.
- 단어장, 단어별 상태/응답 단계·횟수, 탭 위치, 오늘 정답률, 누적 응답 시간을 저장합니다.
- `activeMs`는 완료된 답변의 응답 시간 합계입니다. 멈춤·결과 애니메이션·앱 체류 시간은 포함하지 않습니다.
- 과거 응답 시간이 없던 기록을 추정해 채우지 않습니다.
- 동일 프로필의 동시 저장은 revision 비교로 보호하며, 불일치 시 자동 덮어쓰지 않습니다.
- 최초에 양쪽 기록이 다르면 선택 화면을 보여줍니다. 선택 전 두 기록을 기기에 백업합니다.
- 실패한 저장은 pending 키에 남기고 온라인 복귀/다시 연결에서 재시도합니다.
- 서버 기록 자동 불러오기는 앱 시작 시 수행합니다. 다른 기기 저장 이후에는 새로고침합니다.
- 아직 기기별 이벤트를 병합하는 방식은 아닙니다. 충돌 시 기록 선택이 필요합니다.
- 완전 오프라인 앱 시작(프로필 인증 캐시), 장기간 일별 이력, 서버 검증 배지는 후속 작업입니다.

## 실제 기기 확인
1. 현재 기록이 가장 최신인 기기에서 새 앱을 열고 `서버 저장 완료`를 확인합니다.
2. 한 문제를 답하고 다시 `서버 저장 완료`가 표시될 때까지 기다립니다.
3. 다른 기기에서 같은 프로필로 접속합니다. 기존 기록이 다르면 양쪽 개수를 확인하고 서버 기록을 선택합니다.
4. 마스터/스크랩 개수와 응답 별, 학습 위치를 확인합니다.
5. 양쪽 기기에서 따로 학습했을 때 기록 선택 화면이 나오는지 확인합니다.

백업 키: `<프로필 단어장 키>:sync-backup:<시간>:<UUID>`.
사이트 데이터 삭제는 로컬 백업도 삭제하므로 복구가 필요할 때 삭제하지 않습니다.
